# Blind Auction Project 
 
I created a simple program for blind auctioning 

## How the program works: 

A user is asked to input their name and bid for a blind auction.

Once all bidders have been recorded, the highest bidder is announced as the winner.

## Inside creating this program:
I started with drawing out a flowchart to see what steps I should follow. Creating a flowchart allows me ot visualise my program before I start coding.
- I used a **dictionary** to store the bid records
- Created a **function** to find the highest bidder
- Used a **while loop** to input the user data into the dictionary.
